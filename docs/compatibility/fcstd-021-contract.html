FCStd 0.21+ compatibility contract

FreeCAD Extreme accepts editable FCStd documents written by FreeCAD 0.21 or later when every persisted object type is supplied by the application or an installed extension. Compatibility uses FreeCAD’s existing ZIP/XML persistence and object restoration hooks; it does not introduce another file format or serialization path.

Initial contract

  1. The document opens without a partial restore or missing expected objects.
  2. Feature history, links, and the body tip remain intact.
  3. A full recompute completes without object errors and preserves the reference geometry.
  4. Any restoration hook that changes persisted parameters to retain current behavior emits an explicit diagnostic naming the adjustment and compatibility consequence.
  5. saveCopy() writes the migrated current-format document to a distinct path without changing the source document path.
  6. The saved copy reopens, recomputes, and retains the same history and geometry.

Geometry equality in the initial gate means equal solid/face/edge/vertex counts, volume, and axis-aligned bounds within the test tolerance. This catches loss or behavioral drift without requiring byte-identical OCCT output.

Out of scope

  • Opening newly saved files in older FreeCAD releases.
  • Documents whose required workbench, add-on, font, or external link is unavailable.
  • Byte-for-byte archive or BREP identity, GUI layout, thumbnails, and rendering preferences.
  • Silent repair: partial restoration remains a failure of this contract.
