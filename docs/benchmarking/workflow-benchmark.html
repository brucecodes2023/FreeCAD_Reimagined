Workflow benchmark and kernel gates

TDTest.WorkflowBenchmarkTest exercises one workflow: sketch, pad and pocket, parameter edits, STEP round-trip, and TechDraw projection. Normal test runs enforce deterministic correctness only.

Run it

FreeCAD -t TDTest.WorkflowBenchmarkTest
FREECAD_WORKFLOW_BENCHMARK=1 FreeCAD -t TDTest.WorkflowBenchmarkTest

The opt-in form prints one sorted WORKFLOW_BENCHMARK JSON record. Each stage reports wall-clock seconds. Platforms with Python's resource module also report process peak RSS and its stage increase. Metric values are observations, never correctness assertions.

Kernel experiment boundary

The experiment boundary is the STEP round-trip shape passed to the isolated assertKernelEquivalent comparator. It checks shape validity, one-solid topology counts, volume, and symmetric material difference. It does not introduce a kernel interface, select a replacement kernel, or generalize unrelated geometry.

Adoption gates

  1. The edited model remains valid and has the expected volume.
  2. The STEP result passes the kernel comparator at the recorded tolerance.
  3. The TechDraw view reaches an up-to-date state with the expected visible edges.
  4. Existing focused and module test suites remain green.
  5. Before an experiment starts, its owner records timing and memory budgets for the same runner. Adoption requires meeting those budgets; this test deliberately has no universal hardware-dependent threshold.
